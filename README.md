## Overview

SmartRegister is a web-based school attendance and learner management system designed to simplify attendance tracking, learner administration and attendance reporting.

The application provides separate interfaces for learners and administrators, offering a centralised environment for managing learner information and monitoring attendance activities.

The project focuses on usability, accessibility, security and a clean, responsive user experience.

## Key Features

### Learner Dashboard
- Personal learner dashboard.
- Clock-in and clock-out functionality.
- Personal attendance history.
- Learner profile management.
- Account settings.
- Secure logout.

### Admin Dashboard
- Administrative dashboard.
- Learner management.
- Attendance monitoring.
- Attendance reports.
- Learner record management.
- Administrative controls.
